ماشین‌حساب آروین — پروژه اندروید
این ZIP سورس پروژه است، نه APK آماده.

ساخت APK با گوشی:
1) ZIP را در گوشی استخراج کنید.
2) همهٔ فایل‌های پروژه را در یک مخزن GitHub آپلود کنید (پوشه‌ها و مسیرها باید حفظ شوند).
3) فایل .github/workflows/build-apk.yml باعث ساخت خودکار APK می‌شود.
4) در GitHub به Actions بروید و workflow با نام Build Android APK را اجرا کنید.
5) پس از موفقیت، artifact به نام arvin-debug-apk را دانلود کنید؛ ZIP آن را باز کنید و app-debug.apk را نصب کنید.

این APK آزمایشی/debug است و برای انتشار در بازار یا مایکت باید جداگانه امضا شود.
پرداخت واقعی ۱۰ هزار تومانی هنوز پیاده‌سازی نشده است.
